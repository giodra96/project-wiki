# Project Wiki Document Templates

Use this index to load only the template family needed for the current artifact. Every linked template is complete and copyable; replace placeholders with project-specific values.

| Template Family | Use For |
| --- | --- |
| [Core templates](./core-templates.md) | Root index, registries, schema version, status, project brief, section indexes, and always-on instructions |
| [Requirements and change templates](./requirements-change-templates.md) | Requirement sections and files, open questions, CRs, and ADRs |
| [Technical and implementation templates](./technical-implementation-templates.md) | Module/API docs, scans, sync reports, work items, and traceability maps |
| [Intake and source templates](./intake-source-templates.md) | Source registry/index, intake index, and document review |
| [Governance templates](./governance-templates.md) | Analysis, alerts, maintenance, schema migration, and audit logs |

The authoritative file-to-section inventory and frontmatter contracts live in [`schema/project-wiki.yml`](../schema/project-wiki.yml).
